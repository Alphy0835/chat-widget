## Контекст

Нужен прототип виджета с линейным (сценарным) диалогом без ИИ — пользователь кликает вопрос из списка, получает готовый ответ (см. `team/DECISIONS.md` → D-008). У проекта пока нет базы знаний, поэтому контент для прототипа нужно собрать вручную: часть — с сайта целевого клиента pravoe-delo.su (D-006), часть — придумать как вероятные вопросы посетителей, часть — на основе реальных норм закона о банкротстве физлиц (127-ФЗ), чтобы ответы были не высосаны из пальца, а опирались на факты.

Это MVP-прототип для демонстрации, не полноценная база знаний и не юридическая консультация — упрощение оправдано.

## Задание

1. Изучи сайт https://pravoe-delo.su/ (через WebFetch/WebSearch) — какие услуги предлагают, какие тезисы повторяются, есть ли готовый FAQ-раздел. Возьми оттуда реальные факты об услугах компании (не выдумывай цены/условия, которых нет на сайте — если конкретики нет, пиши ответ в общих словах).
2. Придумай реалистичные вопросы, которые может задать посетитель юридического сайта о списании долгов/банкротстве физлиц: про стоимость, сроки, риски (заберут ли квартиру/машину), последствия (кредитная история, работа, выезд за границу), кто может списать долги, что такое внесудебное банкротство и т.д.
3. Пройдись по ключевым нормам закона №127-ФЗ «О несостоятельности (банкротстве)», глава X (банкротство граждан) — судебная процедура через суд/финансового управляющего, и отдельно — упрощённая процедура внесудебного банкротства через МФЦ (для долгов ограниченного размера). Возьми оттуда 5+ фактов и сформулируй как вопросы-ответы простым языком (не копируй текст закона дословно — перефразируй).
4. Собери всё в `widget/data/qa-data.js` строго по формату из D-008 (`window.ChatWidgetQA = { disclaimer, categories, questions }`).
   - Минимум 20 пар вопрос-ответ, минимум 4 категории (например: «Услуги и стоимость», «Процедура банкротства», «Последствия и риски», «Внесудебное банкротство» — можно скорректировать по факту найденного контента).
   - Каждый ответ — 2–4 коротких предложения, простым языком, без юридического канцелярита и без дословных цитат закона.
   - Обязательно заполни `disclaimer` — явно, что ответы справочные и не заменяют консультацию юриста.
5. В отчёте перечисли источники: ссылку на сайт и конкретные статьи/главы 127-ФЗ, на которые опирались вопросы про закон.

Не входит в задачу: сам движок диалога (кнопки, переключение экранов) — это TASK-007. Не входит: реальная юридическая консультация или проверка фактов юристом — это прототип для демонстрации, не production-контент.

## Критерии приёмки

- [ ] Файл `widget/data/qa-data.js` существует, синтаксически валиден (проверяется `node -e "require('./widget/data/qa-data.js')"` или загрузкой в браузере — не должно быть ошибок в консоли)
- [ ] Структура строго соответствует схеме D-008: объект `window.ChatWidgetQA` с полями `disclaimer` (непустая строка), `categories` (массив с `id`/`title`), `questions` (массив с `id`/`categoryId`/`question`/`answer`)
- [ ] Не менее 20 вопросов-ответов и не менее 4 категорий; у каждого `questions[].categoryId` есть соответствующая категория в `categories`
- [ ] Не менее 5 вопросов явно основаны на нормах 127-ФЗ (глава X), с указанием конкретной статьи в отчёте
- [ ] Ответы написаны простым языком для обычного посетителя, без дословного копирования текста закона
- [ ] `disclaimer` явно указывает на справочный характер ответов
- [ ] В отчёте перечислены источники (сайт + статьи закона)
