# Отчёт по TASK-002: Полная миграция остатка docs-шаблона в docs-archive/

## Что сделано

1. Создана папка `docs-archive/` в корне проекта, в неё перенесены ровно 53 файла из `G:\Мой диск\docs шаблон\docs\` — все `.md`-файлы, которых не было в `docs/` после TASK-001, с сохранением относительной структуры путей (`legal/`, `marketing/`, `operations/`, `product/`, `project/design-guide/...`, `quality/`, `security/`, `support/`, `sync-checklist.md`, `architecture/architecture-decisions/work-rules-architecture-decisions.md`). `desktop.ini` не переносился, исходная папка-шаблон не изменялась и не удалялась.
2. Во всех 53 файлах паспорт сокращён до 4 полей по D-002: `Status`, `Source of truth`, `Update together with`, `Update trigger`. Поля `Doc ID`, `Owner`, `Related docs`, `Review required`, `Maturity` удалены. Значения полей (`draft / active / deprecated`, `yes / no` и т.д.) оставлены как в исходнике — эти файлы неактивны, конкретные значения проставляются при активации тим лидом (это отражено в правиле активации в README архива).
3. Опечатка «зафисимости» → «зависимости» исправлена во всех файлах архива (единственная опечатка из списка задания, встретившаяся в переносимом наборе — «неймнга» и «стадиц» относятся к файлам, уже перенесённым в `docs/` при TASK-001).
4. Ссылки внутри архивных файлов не трогались (по D-003 — чинятся при активации).
5. Создан `docs-archive/README.md` (28 строк): назначение архива, правило активации, список «отложенных» и список «заменённых механизмами команды» доменов/файлов.
6. `docs/maturity-levels.md`: в разделе «Отложенные домены» ссылка на `G:\Мой диск\docs шаблон` заменена на `docs-archive/`.

## Как проверить

```
find docs-archive -name "*.md" | wc -l                          # 54 (53 + README.md)
grep -rl "Owner:\|Review required:\|Related docs:\|Doc ID:" docs-archive/   # пусто
grep -ri "зафисимост\|неймнг\|стадиц" docs-archive/              # пусто
find docs-archive -type d -empty                                 # пусто
find docs-archive -name "desktop.ini"                             # пусто
grep -n "docs-archive" docs/maturity-levels.md                    # строка со ссылкой на docs-archive/, G:\Мой диск больше не упоминается
```

Полнота (объединение docs/ + docs-archive/ должно покрывать все 90 файлов исходника — вручную сверено через `comm`, недостающих нет).

## Замечания для тим лида

- Значения полей паспорта (`Status: draft / active / deprecated` и т.п.) в архиве оставлены как шаблонные placeholder-строки, а не заполнены конкретными значениями (в отличие от TASK-001, где активные файлы `docs/` получили реальные значения). Причина: архивные файлы неактивны, часть из них никогда не активируется («заменённые» класс) — заполнение полей выглядело бы как обязательство поддерживать их. Если это решение неверно — прошу уточнить в DECISIONS.md.
