## Как проверить

```bash
node -e "
global.window = {};
require('./widget/data/qa-data.js');
const d = window.ChatWidgetQA;
console.log(d.disclaimer.length > 0, d.categories.length, d.questions.length);
"
```
Ожидаемый вывод: `true 5 24` — файл грузится без ошибок, disclaimer непустой, 5 категорий, 24 вопроса.
