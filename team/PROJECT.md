# Паспорт проекта

## Цель

Встраиваемый чат-виджет для сторонних сайтов. Владелец сайта вставляет небольшой сниппет кода в свой HTML — виджет отрисовывается поверх страницы независимо от вёрстки и стилей сайта-хоста.

Текущий этап — только визуальная оболочка виджета (плавающая кнопка + окно чата с заглушкой), без реальной логики общения.

В перспективе через виджет будет вестись переписка между посетителем сайта, ИИ-агентом и менеджером (вероятно с интеграцией Битрикс24) — это отдельный, более поздний этап (бэкенд), архитектура которого будет уточнена и зафиксирована в `team/DECISIONS.md`, когда до него дойдёт очередь.

## Стек

- **Frontend виджета** — чистый JavaScript (ES6+, без фреймворков) + CSS. Рендерится внутри Shadow DOM, чтобы стили виджета и сайта-хоста не конфликтовали друг с другом ни в одну, ни в другую сторону.
- **Встраивание** — один `<script>`-тег (loader) на сайте-клиенте (~10–15 строк), создающий контейнер и монтирующий Shadow DOM с виджетом. Конфигурация (позиция, цвет и т.п.) передаётся через `data-*` атрибуты тега.
- **Backend (будущее, не текущий этап)** — Python, вероятно FastAPI, для связи ИИ-агента, менеджера и Битрикс24. Реализуется отдельной задачей, когда будет принято архитектурное решение.
- **Сборка** — без сложного тулчейна на старте (обычные JS/CSS файлы, без бандлера/TypeScript). Минификация/бандлинг — отдельная задача при необходимости деплоя.
- **Хостинг статики** — пока не определён, файлы виджета собираются и лежат в репозитории. Реальный CDN/сервер — отдельная задача при переходе к деплою.

Обоснование зафиксировано в `team/DECISIONS.md`: D-004 (технология и способ встраивания), D-005 (визуальный MVP-паттерн).

## Как запускать

Файлы виджета — обычные браузерные `.js`/`.css`, без шага сборки. Достаточно любого статического HTTP-сервера (открытие `demo.html` напрямую как `file://` тоже работает в современных браузерах, но сервер точнее повторяет реальные условия сайта-клиента).

Из корня репозитория:

```bash
python3 -m http.server 4173
```

Затем открыть в браузере `http://localhost:4173/demo.html`. На странице — плавающая кнопка чата в правом нижнем углу; клик открывает панель. `demo.html` также демонстрирует изоляцию стилей: у страницы намеренно конфликтующие глобальные CSS-правила, которые не должны влиять на вид виджета.

Позицию и цвет виджета можно поменять, отредактировав атрибуты `data-position` / `data-primary-color` у тега `<script>` внизу `demo.html` и перезагрузив страницу.

## Ограничения

- Бюджет пользователя небольшой — модель по умолчанию Sonnet, эскалация только по необходимости (см. `team/PROTOCOL.md`).
- Целевые сайты — произвольные сторонние сайты с разной вёрсткой и стилями → обязательна изоляция стилей виджета (Shadow DOM), никаких глобальных стилей/классов, которые могли бы повлиять на сайт-хост.
- Дизайн — стандартный узнаваемый паттерн chat-виджета (без готового брендбука на старте), но с настраиваемыми через конфиг цветом/позицией.
- Целевые платформы — desktop и mobile web, современные evergreen-браузеры.
