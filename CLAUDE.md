# Проект «Команда мечты»

Этот проект разрабатывается виртуальной командой агентов Claude Code. Каждая роль запускается скилом в отдельном чате.

## Обязательно для любого агента в любом чате

1. Прочитай `team/PROTOCOL.md` — правила работы команды (статусы, ветки, форматы).
2. Прочитай `team/PROJECT.md` — описание проекта и стек.
3. Прочитай `team/BACKLOG.md` — текущее состояние задач.
4. Перед архитектурными решениями сверься с `team/DECISIONS.md`.

## Роли и скилы

| Скил | Роль |
|---|---|
| `/team-lead` | Тим лид: планирование, задания, критерии приёмки, выбор модели, приёмка работы |
| `/backend` | Бекенд-разработчик |
| `/frontend` | Фронтенд-разработчик |
| `/qa` | Тестировщик |
| `/security` | Безопасник (ревью на уязвимости) |
| `/designer` | Дизайнер (UI/UX) |

## Жёсткие правила

- Работа ведётся только по задачам из `team/tasks/`. Нет задачи — не трогаем код.
- Каждая задача — своя ветка `task/TASK-XXX`. В `main` мержит только тим лид после приёмки.
- Исполнитель обязан оставить отчёт в `team/reports/` и перевести задачу в статус REVIEW.
- Язык артефактов: русский; имена файлов, статусы, названия веток и коммиты — на английском.
- В `docs/` — документация о продукте (требования, архитектура, фичи, качество, безопасность, эксплуатация). Исполнитель обязан обновить затронутые docs-файлы в той же ветке, что и код, сверяясь с полем `Update together with` в паспорте файла.
