# Chat Widget

Встраиваемый чат-виджет для сторонних сайтов: владелец сайта вставляет один `<script>`-тег в свой HTML, и поверх страницы (независимо от её вёрстки и стилей) появляется плавающая кнопка чата.

Текущий прототип — сценарный диалог без ИИ и без бэкенда: посетитель выбирает вопрос из категорий или вводит его текстом (нечёткий поиск по базе вопросов-ответов) и получает готовый справочный ответ. Первая целевая площадка — [pravoe-delo.su](https://pravoe-delo.su/) (тема — списание долгов и банкротство физлиц), под её фирменный стиль настроена тема виджета по умолчанию.

## Как посмотреть демо

Файлы виджета — обычные браузерные `.js`/`.css`, без шага сборки.

```bash
python3 -m http.server 4173
```

Открыть в браузере `http://localhost:4173/demo.html`. Плавающая кнопка чата — в правом нижнем углу; клик открывает панель с диалогом.

## Структура

```
widget/
  src/loader.js       — скрипт встраивания: создаёт контейнер, монтирует Shadow DOM
  src/widget.js        — логика виджета: рендер, сценарий диалога, текстовый поиск
  src/widget.css        — стили виджета (изолированы внутри Shadow DOM)
  data/qa-data.js        — база вопросов-ответов для сценарного диалога
  vendor/fuse.min.js      — библиотека нечёткого поиска (Fuse.js, вендорится локально)
demo.html                 — страница-пример встраивания виджета на сайт клиента
```

Подключение на сайте клиента:

```html
<script
  src="widget/src/loader.js"
  data-widget-id="my-widget"
  data-position="bottom-right"
  data-primary-color="#FF4800"
></script>
```
