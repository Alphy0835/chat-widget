## Flow: FLOW-001 — Линейный диалог в чат-виджете

### Actor

Посетитель сайта-клиента (гость, без авторизации).

### Goal

Найти ответ на типовой вопрос через кнопочный сценарий, не дожидаясь оператора и не вводя текст вручную.

### Preconditions

Виджет встроен на странице (loader.js подключён) и на странице подключён `widget/data/qa-data.js`, заполняющий `window.ChatWidgetQA` (формат — team/DECISIONS.md D-008).

### Main Scenario

1. Посетитель кликает по плавающей кнопке чата — открывается панель.
2. При первом открытии панели бот показывает приветствие, дисклеймер (если задан в данных) и кнопки категорий вопросов.
3. Посетитель кликает по категории — бот показывает список кнопок вопросов этой категории и кнопку «‹ Все категории».
4. Посетитель кликает по вопросу — в чат добавляется реплика посетителя с текстом вопроса и реплика бота с готовым ответом, затем кнопки «Другие вопросы этой категории» и «Все категории».
5. Посетитель кликает «Другие вопросы этой категории» (возврат к шагу 3 для той же категории) или «Все категории» (возврат к шагу 2).

### Result

Посетитель получает справочный ответ на вопрос прямо в чате, история переписки остаётся видимой при прокрутке вверх.

### Alternative Scenarios

Посетитель может закрыть панель в любой момент сценария и открыть её снова — прогресс диалога не сохраняется между открытиями (состояние только в памяти текущей загрузки страницы).

### Error / Edge Cases

Если `window.ChatWidgetQA` не подключён на странице или имеет некорректный формат — сценарий не запускается, панель показывает исходную заглушку-плейсхолдер, ошибок в консоли не возникает (FEAT-001).
